# AAI-590 Capstone: Misconception Pattern Classification

**Student:** Monish Yarapathineni  
**Program:** Master of Science in Applied Artificial Intelligence  
**University:** University of San Diego  

## Project Summary

An LSTM-based sequence classifier that infers the type of misconception driving a student's errors from their sequential problem-solving history, using the FoundationalASSIST dataset (Worden et al., 2026).
